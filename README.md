# Практическая работа № 1. Вариант 11

Этап 1: консольный REPL, простой парсер по пробелам, команды-заглушки
`ls`, `cd`, команда `exit`, обработка ошибок.

Требуется Python 3.10 или новее. Внешние пакеты не нужны.

Запуск: `python -m src.main` или `./run.sh` (Windows: `run.bat`).
Тесты: `python -m unittest discover -s tests -v`.

Пример: `ls /home`, `cd /home`, `unknown`, `exit`.
